# Github Repo Agent
Console based chat agent for repositories, using OpenAI API.
- only able to read .py files for now
- 
## ! Before running:
- add OpenAI API key in `.env`

## How to Run:
1. Create a python virtual environment in your local githubAgent folder with `py -m venv venv`
2. Install package requirements with `py -m pip install -r requirements.txt`
3. From your local githubAgent folder, activate the virtual environment with `venv\Scripts\activate`
4. Run githubAgent using `py main.py`
